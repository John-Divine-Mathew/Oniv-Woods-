# Oniv Woods — School of Design Wisdom

Premier architectural design institute and wood technology education platform connecting creators across India and Indonesia to global markets.

## 🌿 About Oniv Woods
Oniv Woods blends traditional woodworking craft, joinery heritage, parametric CAD/CNC technology, and hands-on workshop apprenticeship to shape future-ready product designers, furniture artisans, and spatial leaders.

## ✨ Features & Pages
- **Home**: Luxury editorial experience, 3D/video integrations, course highlights, and ecosystem partners.
- **About Us (`/about`)**: Narrative on the Oniv Woods story, 4 academic pillars, and core values.
- **Courses (`/courses`)**: Filterable course catalog with detailed syllabi, workshop training methodology, and enrollment modals.
- **Course Details (`/course/:id`)**: Week-by-week curriculum timeline, tool specifications, and candidate outcomes.
- **Product Design Challenge (`/challenges`)**: International design competition with sponsored Trade Expo Indonesia (TEI) showcases and global jury reviews.
- **Contact Us (`/contact`)**: Multi-category inquiry suite, studio hubs, validation, and FAQ accordions.

## 🛠️ Technology Stack
- **Framework**: React 19 + Vite 7
- **Routing**: React Router DOM (HashRouter)
- **Styling**: Vanilla CSS Variables + TailwindCSS
- **Animations**: Framer Motion + AOS
- **Icons**: React Icons + Lucide React
- **Email Service**: EmailJS

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/John-Divine-Mathew/Oniv-Woods-.git

# Navigate into the project
cd Oniv-Woods-

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
